# US03 - Movimentação de peça

> Como jogador, quero mover minha peça selecionada para o destino possível que escolhi, para realizar a jogada.

## Requisito Pai

[RF03 - Mover Peça](../../requisitos/requisitos.md)

> Executar o deslocamento da peça selecionada para a casa de destino escolhida pelo jogador.

## Critérios de Aceitação Resumidos

|  ID  | Critério de Aceite | 
| ---- | ------------------ |
| CA01 | Atualização de posição |
| CA02 | Efeitos sonoros na captura |
| CA03 | Alternância de turno |
| CA04 | Negar movimento ilegal |

## Critérios Detalhados

### CA01 - Atualização de posição

- **Dado** que o jogador esteja em uma partida em sua rodada com uma peça selecionada
- **Quando** ele selecionar um movimento legal desejado
- **Então** a peça deve desaparecer da posição inical e aparecer na posição desejada, sobrescrevendo oque estava anteriormente no local

### CA02 - Efeitos sonoros na captura

- **Dado** que o jogador realizou um movimento legal
- **Quando** a peça ocupar a casa de destino 
- **Então** o sistema deve emitir o som de captura caso capture uma peça ou de movimentação caso somente tenha se movido sem ter capturado uma peça

### CA03 - Alternância de turno

- **Dado** que o jogador realizou um movimento legal
- **Quando** a peça ocupar a casa de destino
- **Então** o turno do jogador será encerrado, continuando para o proximo jogador caso não tenha Xeque-Mate

### CA04 - Negar movimento ilegal

- **Dado** que o jogador esteja em uma partida em sua rodada com uma peça selecionada
- **Quando** ele tentar selecionar um movimento legal desejado
- **Então** o sistema não realizara o movimento e a peça sera desselecionada .
