# US03 - Exibição de jogadas possíveis

> Como jogador, quero ver os possíveis movimentos da minha peça selecionada, para que facilite minhas decisões.

## Requisito Pai

[RF03 - Exibir Jogadas Possíveis](../../requisitos/requisitos.md)

> Mostrar indicadores visuais no tabuleiro destacando as casas válidas para onde a peça selecionada pode se mover.

## Critérios de Aceitação Resumidos

|  ID  | Critério de Aceite | 
| CA01 | Exibição de Casas Válidas | 
| CA02 | Remoção dos Destaques |

## Critérios Detalhados

### CA01 - Selecionar Peça Propria

- **Dado** que o jogador esteja em uma partida e seja seu turno
- **Quando** ele selecionar uma peça
- **Entao** todos os movimentos possiveis da peça selecionada serão exibidos no tabuleiro

### CA02 - Remoção dos Destaques

- **Dado** que o jogador tenha uma peça selecionada
- **Quando** o jogador concluir o lance ou cancelar a selecão da peça
- **Entao** os indicadores visuais dos movimentos possiveis irão desaparecer
