# US11 - Exibição das peças capturadas

> Como jogador, quero visualizar as peças que capturei do meu oponente, para ver meu progresso no jogo.

## Requisito Pai

[RF13 - Exibir Peças Capturadas](../../requisitos/requisitos.md)

> Exibir painel dedicado na interface listando todas as peças capturadas por cada jogador ao longo da partida.

## Critérios de Aceitação Resumidos

|  ID  | Critério de Aceite | 
| ---- | ------------------ |
| CA01 | Ativar lista |
| CA02 | Desativar lista |
| CA03 | Nenhuma peça capturada |

### CA01 - Ativar Lista

- **Dado** o jogo não tenha começado e esteja na aba de configurações
- **Quando** o jogador ativar a exibição das peças
- **Então** aparecera uma lista de icones de peças que os jodores capturaram abaixo do seus nomes

### CA02 - Desativar lista

- **Dado** o jogo não tenha começado e esteja na aba de configurações
- **Quando** o jogador desativar a exibição das peças
- **Então** as listas desaparecerão

### CA03 - Nenhuma peça capturada

- **Dado** que a exibição das peças foi ativa
- **Quando** inicia o jogo
- **Então** a lista estara sem nenhum icone

## Evidencias

CA01 - Evidencia dele aqui com imagens ou alguma coisa assim quando estiver sendo feito
