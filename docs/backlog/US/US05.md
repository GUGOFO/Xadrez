# US05 - Exibição do Histórico de movimentos

> Como jogador, quero visualizar o histórico de movimento da partida, para me lembrar qual foi a ordem de jogadas realizadas.

## Requisito Pai

[RF05 - Exibir Histórico de Movimentos](../../requisitos/requisitos.md)

> Apresentar a lista de todas as jogadas realizadas durante a partida.

## Critérios de Aceitação Resumidos

|  ID  | Critério de Aceite | 
| ---- | ------------------ |
| CA01 | Exibir lista do movimento |
| CA02 | Exibir notação padrão com ícone da peça |
| CA02 | Lista vazia |

## Critérios Detalhados

### CA01 - Exibir Lista do movimento

- **Dado** que o usuario esteja na aba de configurações
- **Quando** ele habilitar a lista de movimentos
- **Então** a lista de movimentos ira aparecer ao lado do Tabuleiro de Xadrez em ordem cronologica numerada

### CA02 - Exibir notação padrão com ícone da peça

- **Dado** que um movimento tenha ocorrido
- **Quando** a jogada for registrada no sistema
- **Então** a jogada deve aparecer na lista com a notação algébrica padrão do xadrez e, para peças que não sejam peão, com o ícone da peça movida ao lado

### CA03 - Lista vazia

- **Dado** que uma partida tenha começado e a lista de movimentos esteja ativa
- **Quando** nenhum movimento foi feito
- **Então** a lista deve permanecer vazia
