# US01 - Visualização do Tabuleiro

> Como jogador, quero visualizar o tabuleiro, para jogar o jogo.

## Requisito Pai

[RF01 - Exibir Tabuleiro](../../requisitos/requisitos.md)

> Renderizar o tabuleiro de xadrez centralizado e visível na tela.

## Critérios de Aceitação Resumidos

|  ID  | Critério de Aceite | 
| ---- | ------------------ |
| CA01 | Renderização Inicial |
| CA02 | Exibição Continua |

## Critérios Detalhados

### CA01 - Renderização Inicial

- **Dado** que o jogador entrou no site
- **Quando** a tela inicial for carregada
- **Então** o tabuleiro deve renderizar no centro da tela com todas as peças renderizadas no centro da tela

### CA02 - Exibição Continua

- **Dado** que a partida está em andamento
- **Quando** o jogador interagir com a UI
- **Então** o tabuleiro deve se manter visivel no centro da tela
