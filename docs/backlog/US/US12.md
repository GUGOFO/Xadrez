# US12 - Exibição dos espaços seguros

> Como jogador, quero visualizar os espaços seguros que meu rei pode movimentar ao receber xeque, para decidir meu próximo movimento mais rapidamente.

## Requisito Pai

[RF14 - Exibir Espaços Seguros](../../requisitos/requisitos.md)

> Destacar as casas seguras para onde o Rei pode se mover caso esteja sob condição de xeque.

## Critérios de Aceitação Resumidos

|  ID  | Critério de Aceite | 
| ---- | ------------------ |
| CA01 | Ativar exibição de espacos seguros |
| CA02 | Mostrar espaço seguros |
| CA03 | Desativar exibição espaço seguros |
| CA04 | Desativar espaço seguros |

### CA01 - Ativar exibição de espaços seguros

- **Dado** o jogo nao tenha comecado e esteja na aba de configurações
- **Quando** o jogador ativar a exibição de espaços
- **Então** a funcionalidade ira ser aplicada nos proximos jogos

### CA02 - Mostrar espaço seguros

- **Dado** que o jogo tenha começado
- **Quando** o jogador recebeu um xeque que nao seja mate
- **Então** todos os movimentos que tirão to xeque serão exibidos

### CA03 - Desativar exibição espaço seguros

- **Dado** o jogo nao tenha comecado e esteja na aba de configurações
- **Quando** o jogador desativar a exibição de espaços
- **Então** a funcionalidade ira ser desativa para os proximos jogos

### CA04 - Desativar espaço seguros

- **Dado** que o jogador tenha recebido um xeque
- **Quando** o jogdaor sair do xeque ou for xequemate
- **Então** os espacos seguros voltarao ao normal

## Evidencias

CA01 - Evidencia dele aqui com imagens ou alguma coisa assim quando estiver sendo feito
