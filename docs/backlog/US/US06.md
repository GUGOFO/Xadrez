# US06 - Modificação das Cores

> Como jogador, quero modificar as cores das minhas peças, para deixar o jogo mais personalizado.

## Requisito Pai

[RF07 - Modificar Cores](../../requisitos/requisitos.md)

> Disponibilizar opções de personalização para as cores das peças.

## Critérios de Aceitação Resumidos

|  ID  | Critério de Aceite | 
| ---- | ------------------ |
| CA01 | Seleção de cor das peças |
| CA02 | Persistencia entre partidas |
| CA03 | Diferença de cores entre jogadores |

## Critérios Detalhados

### CA01 - Seleção de cor das peças

- **Dado** que o jogador esteja na aba de configurações
- **Quando** ele selecionar a cor de um jogador
- **Então** as peças dele devem trocar para essa cor

### CA02 - Persistencia entre partidas

- **Dado** que o jogador tenha uma cor escolhida e termine uma partida
- **Quando** ele inicia outra partida não alterando sua cor
- **Então** a sua cor deve se manter igual

### CA03 - Diferença de Cores entre Jogadores

- **Dado** que o Jogador 1 já selecionou uma cor para suas peças
- **Quando** o Jogador 2 tentar selecionar a mesma cor
- **Então** o sistema deve impedir a seleção
