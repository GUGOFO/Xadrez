# US07 - Alteração dos Nomes

> Como jogador, quero alterar os nomes dos jogadores antes de iniciar a partida, para deixar o jogo mais pessoal para nos jogadores.

## Requisito Pai

[RF08 - Alterar Nomes](../../requisitos/requisitos.md)

> Permitir a edição dos nomes de exibição dos dois jogadores antes do início da partida.

## Critérios de Aceitação Resumidos

|  ID  | Critério de Aceite | 
| ---- | ------------------ |
| CA01 | Alterar nome |
| CA02 | Sem nome |
| CA03 | Nomes identicos |
| CA04 | Nomes gigantes |

## Critério de Aceitação Detalhados

### CA01 - Alterar nome

- **Dado** que o jogador esteja na aba de configuração
- **Quando** ele trocar seu nome
- **Então** deve ser refletido no canto do tabuleiro onde estao suas peças

### CA02 - sem nome

- **Dado** que o jogador tenha um nome
- **Quando** ele tentar trocar para um nome Nulo
- **Então** o sistema deve impedir a troca

### CA03 - Nomes identicos

- **Dado** que o jogador 1 tenha um nome X
- **Quando** o jogador 2 tentar trocar para o nome X
- **Então** o sistema deve impedir a troca

### CA04 - Nomes gigantes

- **Dado** que o jogador tente trocar o nome
- **Quando** ele colocar um nome maior de 32 digitos 
- **Então** o sistema deve impedir a troca
