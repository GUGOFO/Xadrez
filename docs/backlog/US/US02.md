# US02 - Seleção de Peças

> Como jogador, quero clicar nas minhas peças, para que fique selecionada.

## Requisito Pai

[RF02 - Selecionar Peça](../../requisitos/requisitos.md)

> Permitir a seleção de uma peça própria ao clicar ou tocar sobre ela, habilitando o acesso às opções de movimento.

## Critérios de Aceitação Resumidos

|  ID  | Critério de Aceite | 
| ---- | ------------------ |
| CA01 | Selecionar Peça Própria |
| CA02 | Feedback Visual e Casas Válidas |
| CA03 | Trocar Peça Selecionada |
| CA04 | Desselecionar Peça |

## Critérios Detalhados

### CA01 - Selecionar Peça Própria 

- **Dado** que uma partida tenha sido iniciada
- **Quando** for o turno do jogador e ele clicar em uma peça de sua própria cor
- **Então** o sistema deve marcar essa peça como selecionada para a jogada

### CA02 - Feedback Visual e Casas Válidas 

- **Dado** que o jogador selecionou uma peça de sua propriedade
- **Quando** a seleção for confirmada pelo sistema
- **Então** o sistema deve aplicar um destaque visual sobre a peça selecionada e exibir os indicadores visuais em todas as casas para onde ela pode se mover legalmente

### CA03 - Trocar Peça Selecionada 

- **Dado** que o jogador já possui uma peça selecionada
- **Quando** ele clicar em outra peça de sua própria cor
- **Então** o sistema deve remover a seleção e os destaques da peça anterior e selecionar a nova peça imediatamente

### CA04 - Desselecionar Peça 

- **Dado** que o jogador possui uma peça selecionada
- **Quando** ele clicar novamente sobre a mesma peça selecionada
- **Então** a peça deve ser desselecionada e todos os destaques visuais do tabuleiro devem ser desativados
