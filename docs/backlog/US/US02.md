# US02 - Seleção de Peças

> Como jogador, quero clicar nas minhas peças, para que fique selecionada para a jogada.

## Requisito Pai

[RF02 - Selecionar Peça](../../requisitos/requisitos.md)

> Permitir a seleção de uma peça própria ao clicar ou tocar sobre ela, habilitando o acesso às opções de movimento.

## Critérios de Aceitação Resumidos

|  ID  | Critério de Aceite | 
| ---- | ------------------ |
| CA01 | Selecionar Peça Propria |
| CA02 | FeedBack Visual |
| CA03 | Trocar Peça Selecionada |
| CA04 | Descelecionar Peça |

## Critérios Detalhados

### CA01 - Selecionar Peça Propria

- **Dado** que uma partida tenha cido iniciada
- **Quando** for a vez do jogador
- **Então** ele podera selecionar uma de suas peças

### CA02 - FeedBack Visual

- **Dado** que uma partida tenha sido iniciada e seja a vez do jogador
- **Quando** ele selecionar a peça
- **Então** o sistema deve ter um feedback visual sobre a peça selecionada

### CA03 - Trocar Peça Selecionada

- **Dado** que o jogador tenha selecionado uma peça
- **Quando** o jogador selecionar outra peça
- **Então** o sistema deve deselecionar a peça anterior e selecionar a nova peça

### CA04 - Descelecionar Peça

- **Dado** que o jogador tenha selecionado uma peça
- **Quando** o jogador clicar sobre uma peça selecionada
- **Então** a peça deve ser deselecionada
