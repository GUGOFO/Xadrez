# US04 - Alteração de tempo de Jogo

> Como jogador, quero selecionar quanto tempo total e extra cada jogador deve ter, para controlar a duração máxima do jogo.

## Requisito Pai

[RF04 - Alterar Tempo de Jogo](../../requisitos/requisitos.md)

> Permitir a configuração do tempo total de partida para cada jogador e a definição do tempo de bônus por jogada.

## Critérios de Aceitação Resumidos

|  ID  | Critério de Aceite | 
| ---- | ------------------ |
| CA01 | Definição do Tempo Fixo |
| CA02 | Definição do Bonus de Tempo |

## Critérios Detalhados

### CA01 - Definição do Tempo Fixo

- **Dado** que esteja na aba de configurações
- **Quando** o usuario seleciona um tempo fixo
- **Então** o sistema deve atualizar o cronômetro inicial de ambos os jogadores para o tempo escolhido

### CA02 - Definição do Bonus de Tempo

- **Dado** que esteja na aba de configurações
- **Quando** o usuario seleciona um bonus de tempo
- **Então** o sistema deve adicionar o incremento a cada jogada realizada
