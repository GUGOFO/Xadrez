# US008 - Desistência da Partida

> Como jogador, quero poder desistir da partida em que estou jogando, para declarar minha derrota sem ter que prolongar o jogo.

## Requisito Pai

[RF09 - Desistir da Partida](../../requisitos/requisitos.md)

> Disponibilizar opção para encerramento voluntário da partida, declarando o oponente como vencedor.

## Critérios de Aceitação Resumidos

|  ID  | Critério de Aceite | 
| ---- | ------------------ |
| CA01 | PopUp de Garantia |
| CA02 | Desistencia da partida |
| CA03 | Desistencia fora de partida |

## Critérios Detalhados

### CA01 - PopUp de Garantia

- **Dado** os jogadores estejam em uma partida
- **Quando** um jogador clicar no botão de desistencia
- **Então** um popUp ira aparecer perguntando se ele deseja mesmo desistir da partida

### CA02 - Desistencia da partida

- **Dado** os jogadores estejam em uma partida e um deles tenha clicado no botão de desistencia
- **Quando** o jogador aconfirmar o popUp
- **Então** o jogador que desistiu ira perder a partida

### CA03 - Desistencia fora de partida

- **Dado** não estejam em uma partida
- **Quando** um jogador clicar no botao de desistir
- **Então** o botão não deve fazer nada
