# US09 - Proposição de Empate

> Como jogador, quero poder propor um empate para meu oponente, para não prolongar o jogo que nós sabemos que dará um empate.

## Requisito Pai

[RF10 - Propor Empate](../../requisitos/requisitos.md)

> Disponibilizar o envio de solicitação de empate por mútuo acordo e encerrar a partida se a solicitação for aceita.

## Critérios de Aceitação Resumidos

|  ID  | Critério de Aceite | 
| ---- | ------------------ |
| CA01 | PopUp de Garantia |
| CA02 | Empate da partida |
| CA03 | Empate Negado |
| CA04 | Empate fora de partida |

## Critérios Detalhados

### CA01 - PopUp de Garantia

- **Dado** os jogadores estejam em uma partida
- **Quando** um jogador clicar no botão de empate ou aceitar o empate do oponente
- **Então** um popUp ira aparecer perguntando se ele deseja mesmo pedir um empate

### CA02 - Empate da partida

- **Dado** os jogadores estejam em uma partida
- **Quando** ambos aceitam um empate
- **Então** o jogo terminara em um empate

### CA03 - Empate Negado

- **Dado** os jogadores estejam em uma partida e um peça um empate
- **Quando** o segundo jogador negar
- **Então** o jogo continuara

### CA04 - Empate fora de partida

- **Dado** não estejam em uma partida
- **Quando** um jogador clicar no botao de empate
- **Então** o botão não deve fazer nada
