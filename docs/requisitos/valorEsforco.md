# Matriz de Valor vs. Esforço

| ID | Requisito |
| :--- | :--- |
| **RF01** | Exibir Tabuleiro |
| **RF02** | Selecionar Peça |
| **RF04** | Mover Peça |
| **RF05** | Alterar Tempo de Jogo |
| **RF08** | Modificar Cores |
| **RF09** | Alterar Nomes |
| **RF10** | Desistir da Partida |
| **RF11** | Propor Empate |
| **RF12** | Exibir Resultado |
