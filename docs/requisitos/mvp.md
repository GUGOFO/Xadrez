# Produto Mínimo Viável (MVP)

| ID | Requisito | Prioridade | Descrição |
| :--- | :--- | :--- | :--- |
| **RF01** | Exibir Tabuleiro | Must Have | Renderizar o tabuleiro de xadrez centralizado e visível na tela. |
| **RF02** | Selecionar Peça | Must Have | Permitir a seleção de uma peça própria ao clicar ou tocar sobre ela, habilitando o acesso às opções de movimento. |
| **RF03** | Mover Peça | Must Have | Executar o deslocamento da peça selecionada para a casa de destino escolhida pelo jogador. |
| **RF04** | Alterar Tempo de Jogo | Should Have | Permitir a configuração do tempo total de partida para cada jogador e a definição do tempo de bônus por jogada. |
| **RF05** | Exibir Histórico de Movimentos | Should Have | Registrar e apresentar a lista de todas as jogadas realizadas durante a partida. |
| **RF07** | Modificar Cores | Should Have | Disponibilizar opções de personalização para as cores das peças. |
| **RF08** | Alterar Nomes | Should Have | Permitir a edição dos nomes de exibição dos dois jogadores antes do início da partida. |
| **RF09** | Desistir da Partida | Must Have | Disponibilizar opção para encerramento voluntário da partida, declarando o oponente como vencedor. |
| **RF10** | Propor Empate | Must Have | Disponibilizar o envio de solicitação de empate por mútuo acordo e encerrar a partida se a solicitação for aceita. |
| **RF11** | Exibir Resultado | Must Have | Apresentar tela ao final da partida contendo o resultado final. |
| **RF13** | Exibir Peças Capturadas | Should Have | Exibir painel dedicado na interface listando todas as peças capturadas por cada jogador ao longo da partida. |
| **RF14** | Exibir Espaços Seguros | Should Have | Destacar as casas seguras para onde o Rei pode se mover caso esteja sob condição de xeque. |
| **RF15** | Exibir Configurações | Must Have | Apresentar uma tela de configurações geral do sistema. |
| **RF16** | Iniciar Partida | Must Have | Iniciar uma partida com as configurações já salvas. |
