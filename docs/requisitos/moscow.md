# MoSCoW

A matriz MoSCoW abaixo prioriza as funcionalidades do sistema com base nos Requisitos Funcionais.

---

## Must Have
| ID | Requisito |
| :--- | :--- |
| **RF01** | Exibir Tabuleiro |
| **RF02** | Selecionar Peça |
| **RF03** | Mover Peça | 
| **RF09** | Desistir da Partida |
| **RF10** | Propor Empate |
| **RF11** | Exibir Resultado | 
| **RF15** | Exibir Configurações | 

---

## Should Have

| ID | Requisito |
| :--- | :--- |
| **RF04** | Alterar Tempo de Jogo |
| **RF05** | Exibir Histórico de Movimentos |
| **RF07** | Modificar Cores |
| **RF08** | Alterar Nomes |
| **RF13** | Exibir Peças Capturadas |
| **RF14** | Exibir Espaços Seguros | 

---

## Could Have

| ID | Requisito |
| :--- | :--- |
| **RF06** | Voltar Movimentos |
| **RF12** | Editar Tabuleiro |

---

## Won't Have

Nenhum item esta no Won’t have.
